# CuratorMD V2 VS Code status label

This separate V2-owned VS Code extension displays `CuratorMD V2` in the
bottom status bar. Its neutral label does not report service health, capture,
persistence, or authenticated identity.

For local development, open this directory in VS Code and run **Developer:
Install Extension from Location...** from the Command Palette. Reload the
window to activate it. The status item's tooltip and click action repeat the
health-check limitation.
